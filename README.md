# Deep Neural Networks

Implementation of fundamental and advanced Deep Neural Network architectures, with a focus on understanding the underlying concepts and training process.

### Implementations

* **Linear Neural Network**

  * Regression — from scratch and PyTorch
  * Classification — from scratch and PyTorch

* **Multi-Layer Perceptron (MLP)**

  * Regression — from scratch and PyTorch
  * Classification — from scratch and PyTorch
  * Unified implementation supporting both tasks

* **Convolutional Neural Networks**

  * CNN implementation using PyTorch
  * Forward propagation and training
  * Backpropagation through convolution, pooling, and fully connected layers

### CNN Architectures

Implemented the following architectures using PyTorch:

* **AlexNet**
* **Network in Network (NiN)**
* **VGG**
* **GoogLeNet / Inception**
* **ResNet**
