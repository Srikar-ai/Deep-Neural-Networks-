# Deep Neural Networks

Implementation of fundamental and advanced deep learning architectures, with a focus on understanding their underlying mathematics, forward propagation, backpropagation, and training processes.

## Implementations

### 1. Linear Neural Networks
- Regression — from scratch using NumPy and with PyTorch
- Classification — from scratch using NumPy and with PyTorch

### 2. Multi-Layer Perceptron (MLP)
- Regression — from scratch using NumPy and with PyTorch
- Classification — from scratch using NumPy and with PyTorch
- Unified implementation supporting both regression and classification

### 3. Convolutional Neural Networks (CNNs)
- CNN implementation using PyTorch
- Forward propagation and model training
- Understanding backpropagation through convolutional, pooling, and fully connected layers

### 4. CNN Architectures
Implemented the following architectures using PyTorch:

- AlexNet
- Network in Network (NiN)
- VGG
- GoogLeNet / Inception
- ResNet

### 5. Sequence Modeling and Recurrent Neural Networks

Exploring the evolution of sequence modeling, from statistical language models to neural networks.

- **Unigram Language Model** — word-frequency counting and frequency-based prediction
- **N-gram Language Model** — Markov assumption, conditional probability, and next-word prediction
- **Laplace Smoothing** — handling unseen n-grams and zero probabilities
- **Vanilla RNN from Scratch** — hidden-state computation, recurrent connections, and sequence processing using NumPy
- **RNN with PyTorch** — sequence modeling using `torch.nn.RNN`, automatic differentiation, and backpropagation through time (BPTT)
